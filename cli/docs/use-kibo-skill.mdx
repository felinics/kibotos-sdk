**`use-kibo`** is the official Agent Skill for **Kibotos**, located at `skills/use-kibo/` in the `felinics/kibotos-sdk` repository. It teaches AI coding agents how to verify authentication, drive `kibo` with explicit arguments and `--no-input --json`, parse structured errors and exit codes, protect API keys, and confirm destructive operations.

## What `use-kibo` Includes

```text
skills/use-kibo/
├── SKILL.md                     # Preflight checks, operating discipline, and core recipes
└── references/
    ├── cli-reference.md         # Full kibo command tree, flags, precedence, and error codes
    └── workflows.md             # End-to-end agent workflows and troubleshooting playbooks
```

When loaded, `use-kibo` instructs agents to:

1. **Preflight with `kibo whoami --json`** before creating or mutating resources, guiding the user through `kibo login` (or `KIBOTOS_API_KEY`) on exit code `3` instead of guessing credentials.
2. **Provide all required inputs with `--no-input --json`**. Results go to stdout, including one JSON event per line for streaming exec. Errors and progress go to stderr. Use a local destination with `files get --json`. Use `-q` for bare IDs.
3. **Wait for asynchronous lifecycle commands by default**. Use `--no-wait` when you plan to wait separately.
4. **Act on exit codes and `error.retryable`** (`0` success, `1` API/runtime error, `2` usage error, `3` unauthenticated).
5. **Protect secrets and confirm intent for destructive actions** such as deleting resources or files, force-stopping, revoking live exposures, or clearing bindings. Automation skips terminal confirmations.

## Prerequisite: Install & Authenticate `kibo`

Make sure the `kibo` binary is on your `PATH` and authenticated:

```bash
kibo login
kibo whoami --json
```

## Installing `use-kibo` in Your AI Coding Agent

Clone or download `skills/use-kibo/` from [`felinics/kibotos-sdk`](https://github.com/felinics/kibotos-sdk):

```bash
git clone --depth 1 https://github.com/felinics/kibotos-sdk.git /tmp/kibotos-sdk
```

Then copy `skills/use-kibo` into your agent's skills directory:

### Claude Code

```bash
# User-global skill
mkdir -p ~/.claude/skills
cp -R /tmp/kibotos-sdk/skills/use-kibo ~/.claude/skills/use-kibo

# Or project-scoped skill
mkdir -p .claude/skills
cp -R /tmp/kibotos-sdk/skills/use-kibo .claude/skills/use-kibo
```

### OpenAI Codex

```bash
mkdir -p ~/.codex/skills
cp -R /tmp/kibotos-sdk/skills/use-kibo ~/.codex/skills/use-kibo
```

### Cursor

```bash
# Project-scoped skill (or ~/.cursor/skills/use-kibo for global)
mkdir -p .cursor/skills
cp -R /tmp/kibotos-sdk/skills/use-kibo .cursor/skills/use-kibo
```

### Antigravity

```bash
# User-global skill
mkdir -p ~/.gemini/antigravity/skills
cp -R /tmp/kibotos-sdk/skills/use-kibo ~/.gemini/antigravity/skills/use-kibo

# Or workspace-scoped skill
mkdir -p .agents/skills
cp -R /tmp/kibotos-sdk/skills/use-kibo .agents/skills/use-kibo
```

Clean up the temporary clone afterwards:

```bash
rm -rf /tmp/kibotos-sdk
```

## Example Prompts

Once `use-kibo` is installed, ask your agent naturally:

- *"Spin up a Kibotos `python-3.12` workspace with 2 vCPUs, 4 GiB RAM, and a 1-hour auto-stop timeout, wait until it's available, and expose port 8080."*
- *"Create a 50 GiB persistent Kibotos volume in `global-1`, attach it at `/data` to a new workspace, and return the workspace ID."*
- *"Lock down outbound internet access (`deny_all`) on workspace `wks_...` and confirm the policy is applied."*
- *"List all available Kibotos workspaces labeled `env=staging` and check their auto-timeout expiry."*
- *"Run `uname -a` in workspace `wks_123` and return its exit status and output."*
