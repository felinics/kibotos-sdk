`@kibotos/sdk` is the official zero-dependency TypeScript and JavaScript SDK for the **Kibotos** v1 API. It is built on standard Web APIs (`fetch`, `ReadableStream`, `AbortSignal`, `WebSocket`, `crypto.randomUUID`) and covers the control plane (workspaces, volumes, exposures, Packs, egresses, resolvers) and the workspace data plane (exec, files, metrics, tunnels, proxy, desktop).

## Requirements & Runtime Compatibility

- **Node.js**: 20.0.0 or later
- **Bun**, **Deno**, **Cloudflare Workers**, and other edge runtimes with global `fetch`
- **Module formats**: Dual ESM (`import`) and CommonJS (`require`) with bundled `.d.ts` / `.d.cts` type definitions

The HTTP API works in every runtime above. Authenticated WebSocket helpers (`connectWS`, `connectTunnel`, `connectDesktop`, `connectProxy`) use Node's built-in `WebSocket` and need a `factory` option in runtimes whose `WebSocket` cannot send handshake headers. See [WebSocket runtime support](./exec-files-and-tunnels#websocket-runtime-support).

## Installation

```bash
npm install @kibotos/sdk
```

Or with your preferred package manager:

```bash
pnpm add @kibotos/sdk
# or
bun add @kibotos/sdk
```

## Quickstart

Set `KIBOTOS_API_KEY` in your environment (or pass `apiKey` to `new Kibotos(...)`):

```bash
export KIBOTOS_API_KEY="kb_..."
```

Create a workspace, run a command in it, expose a port, and clean up:

```ts
import { Kibotos } from '@kibotos/sdk';

const client = new Kibotos();

// 1. Create a workspace (asynchronous; returns the initial Workspace)
const created = await client.workspaces.create({
  name: 'agent-runner',
  template: { id: 'python-3.12' },
  resources: { vcpus: 2, memory_mib: 4096 },
  timeout: { seconds: 3600, action: 'stop' },
  labels: { env: 'dev' },
});

// 2. Wait until it is available (timeouts over 60s are chunked automatically)
const workspace = await client.workspaces.wait(created.id, {
  status: ['available', 'failed'],
  timeoutSeconds: 120,
});
console.log('Workspace ready:', workspace.id, workspace.status);

// 3. Run a command
const result = await client.workspaces.exec(workspace.id, {
  argv: ['python3', '--version'],
});
console.log(result.exit_code, result.stdout);

// 4. Expose port 8080 on a temporary HTTPS URL
const exposure = await client.exposures.create(workspace.id, {
  port: 8080,
  ttl_seconds: 3600,
});
console.log('Public URL:', exposure.url);

// 5. Clean up
await client.exposures.revoke(workspace.id, exposure.id);
await client.workspaces.delete(workspace.id);
```

## Client Configuration

Pass a `KibotosClientOptions` object to `new Kibotos(options)`:

```ts
import { Kibotos } from '@kibotos/sdk';

const client = new Kibotos({
  apiKey: 'kb_...',
  baseUrl: 'https://api.kibo.to/v1',
  maxRetries: 3,
  timeoutMs: 30_000,
  defaultHeaders: { 'X-App': 'my-service' },
  fetch: globalThis.fetch,
});
```

### `KibotosClientOptions`

| Option | Type | Env Fallback | Default | Description |
| --- | --- | --- | --- | --- |
| `apiKey` | `string` | `KIBOTOS_API_KEY` | `undefined` | Organization API key (`kb_...`). Sent as `Authorization: Bearer <apiKey>`. |
| `baseUrl` | `string` | `KIBOTOS_API_URL` | `'https://api.kibo.to/v1'` | API base URL. Trailing slashes are trimmed and `/v1` is appended when missing. |
| `maxRetries` | `number` | — | `3` | Maximum retry attempts for retryable API errors, HTTP `429`/`5xx`, and network errors. Set `0` to disable retries. |
| `timeoutMs` | `number` | — | `30000` | Default per-request HTTP timeout in milliseconds. |
| `fetch` | `typeof globalThis.fetch` | — | `globalThis.fetch` | Custom `fetch` implementation for testing or custom runtimes. |
| `defaultHeaders` | `Record<string, string>` | — | `{}` | Additional headers merged into every request and WebSocket handshake. |

The read-only `client.baseUrl` getter returns the normalized base URL (always ending in `/v1`).

> **Cloudflare Workers and browser-like runtimes**: `process.env` is unavailable, so read the secret from your worker `env` binding and pass `new Kibotos({ apiKey: env.KIBOTOS_API_KEY })`.

## Per-Request Options

Every HTTP method accepts an optional trailing `opts?: RequestOptions` argument:

```ts
interface RequestOptions {
  idempotencyKey?: string;
  signal?: AbortSignal;
  timeoutMs?: number;
  headers?: Record<string, string>;
}
```

File methods extend it with a workspace `user` (`FileOptions`), plus `depth` for listings, `range` / `ifNoneMatch` / `as` for reads, and `mode` / `createOnly` for writes.

All request, response, and option types are exported from the package root:

```ts
import type { CreateWorkspaceRequest, ExecResponse, Workspace } from '@kibotos/sdk';
```

See [Errors & Retries](./errors-and-retries) for automatic retries, `Idempotency-Key` handling, and cancellation with `AbortSignal`.
