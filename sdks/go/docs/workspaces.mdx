Manage microVM workspaces via `client.Workspaces` (`*kibotos.WorkspacesService`). Running commands, transferring files, and opening tunnels are covered in [Exec, Files & Tunnels](./exec-files-and-tunnels).

## Create a Workspace

`client.Workspaces.Create(ctx context.Context, params CreateWorkspaceParams, opts ...RequestOption) (*Workspace, error)`

Provisions a workspace asynchronously (`POST /v1/workspaces`, HTTP `202 Accepted`). Only `Template.ID` is required.

```go
ws, err := client.Workspaces.Create(ctx, kibotos.CreateWorkspaceParams{
	Name: "ml-sandbox",
	Zone: "global-1",
	Template: kibotos.WorkspaceTemplateSpec{
		ID:       "python-3.12",
		Revision: "rev_20260101",
	},
	Resources: &kibotos.WorkspaceResourcesSpec{
		VCPUs:     4,
		MemoryMiB: 8192,
		DiskMiB:   20480,
	},
	Network: &kibotos.WorkspaceNetworkSpec{
		Mode: kibotos.NetworkModePublicInternet,
		Deny: []string{"10.0.0.0/8"},
	},
	Volumes: []kibotos.WorkspaceVolumeInput{
		{ID: "vol_data", MountPath: "/data"},
		{ID: "vol_cache", MountPath: "/cache", DeleteWithWorkspace: true},
	},
	Packs: []string{"node-22"},
	Timeout: &kibotos.TimeoutSpec{
		Seconds: 3600,
		Action:  kibotos.TimeoutActionStop,
	},
	Labels: map[string]string{
		"team": "ml",
		"env":  "staging",
	},
}, kibotos.WithIdempotencyKey("ml-sandbox-create-1"))
```

### `CreateWorkspaceParams` Fields

| Field | Type | Description |
| --- | --- | --- |
| `Template` | `WorkspaceTemplateSpec` | Required `ID` and optional pinned `Revision`. |
| `Name` | `string` | Human-readable workspace name. |
| `Zone` | `string` | Target zone ID (defaults to the organization's default zone). |
| `Resources` | `*WorkspaceResourcesSpec` | `VCPUs`, `MemoryMiB`, `DiskMiB` overrides. |
| `Network` | `*WorkspaceNetworkSpec` | Outbound policy: `Mode` plus optional `Allow`, `Deny`, `Egresses`, `Resolvers`. See [Packs & Networking](./packs-and-networking#outbound-network-policy). |
| `Volumes` | `[]WorkspaceVolumeInput` | Volumes to attach at creation. Each must be in the workspace's zone. |
| `Volume` | `*WorkspaceVolumeSpec` | Legacy single-volume form of `Volumes`. |
| `Packs` | `[]string` | Up to four unique Pack IDs. |
| `Timeout` | `*TimeoutSpec` | Auto-timeout: `Seconds` and optional `Action`. |
| `Labels` | `map[string]string` | Key-value metadata labels. |

`CreateWorkspaceRequest` is an alias of `CreateWorkspaceParams`. The returned `Workspace` reports attachments in `Volumes` (and the legacy `Volume` field), bound Packs in `Packs` (`WorkspacePack` with `ID`, `Revision`, `ProvidedCapabilities`), and the active policy in `Network`.

## Wait for a Target Status

`client.Workspaces.Wait(ctx context.Context, id string, params WaitWorkspaceParams, opts ...RequestOption) (*Workspace, error)`

Blocks until the workspace reaches one of `params.Statuses`, fails with `unexpected_status`, or the timeout/context deadline expires. When `Timeout` (or `ctx` deadline) exceeds 60 seconds, `Wait` automatically loops across `<= 60s` server long-poll windows.

```go
ws, err := client.Workspaces.Wait(ctx, created.ID, kibotos.WaitWorkspaceParams{
	Statuses: []kibotos.WorkspaceStatus{
		kibotos.WorkspaceStatusAvailable,
		kibotos.WorkspaceStatusFailed,
	},
	Timeout: 3 * time.Minute,
})
if err != nil {
	log.Fatal(err)
}
if ws.Status == kibotos.WorkspaceStatusFailed && ws.Failure != nil {
	log.Fatalf("workspace failed: %s: %s", ws.Failure.Code, ws.Failure.Message)
}
```

Available `WorkspaceStatus` constants: `WorkspaceStatusCreating`, `WorkspaceStatusAvailable`, `WorkspaceStatusStopping`, `WorkspaceStatusStopped`, `WorkspaceStatusStarting`, `WorkspaceStatusDeleting`, `WorkspaceStatusFailed`, `WorkspaceStatusUnknown`.

## List and Iterate Workspaces (`iter.Seq2`)

### Single Page (`List`)

Returns `*kibotos.MultiZonePage[kibotos.Workspace]`:

```go
page, err := client.Workspaces.List(ctx, &kibotos.WorkspaceListParams{
	Status: kibotos.WorkspaceStatusAvailable,
	Zone:   "global-1",
	Labels: map[string]string{"team": "ml"},
	Limit:  20,
})
if err != nil {
	log.Fatal(err)
}
fmt.Printf("Count: %d, HasMore: %t, UnavailableZones: %v\n",
	len(page.Data), page.HasMore(), page.UnavailableZones)
```

### Auto-Pagination (`Iter`)

`Iter` returns `iter.Seq2[kibotos.Workspace, error]` for idiomatic `for ... range` iteration across all pages:

```go
for ws, err := range client.Workspaces.Iter(ctx, &kibotos.WorkspaceListParams{
	Status: kibotos.WorkspaceStatusAvailable,
	Labels: map[string]string{"team": "ml"},
}) {
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println(ws.ID, ws.Name, ws.Zone)
}
```

## Get, Update (`Nullable[T]`), and Delete

`UpdateWorkspaceParams` uses `kibotos.Nullable[string]` for `Name` so you can distinguish three states during `PATCH /v1/workspaces/{id}`:

- Leave `Name` zero-valued (`Nullable[string]{}`) to **omit** `"name"` from JSON.
- Use `kibotos.Some("new-name")` to set `"name": "new-name"`.
- Use `kibotos.Null[string]()` to clear the name (`"name": null`).

In `Labels` (`map[string]*string`), non-nil pointers set a label (`kibotos.Ptr("value")`) and `nil` deletes that label key:

```go
// Fetch a workspace
ws, err := client.Workspaces.Get(ctx, "wks_01j9...")

// Rename and update/remove labels
ws, err = client.Workspaces.Update(ctx, ws.ID, kibotos.UpdateWorkspaceParams{
	Name: kibotos.Some("renamed-sandbox"),
	Labels: map[string]*string{
		"owner":          kibotos.Ptr("platform"),
		"deprecated_tag": nil, // deletes this label key
	},
})

// Clear the workspace name explicitly
ws, err = client.Workspaces.Update(ctx, ws.ID, kibotos.UpdateWorkspaceParams{
	Name: kibotos.Null[string](),
})

// Delete asynchronously (HTTP 202)
deleting, err := client.Workspaces.Delete(ctx, ws.ID)
```

## Resize a Workspace

`UpdateWorkspaceParams.Resources` resizes a workspace. It must be `stopped` or `failed` to change vCPUs or memory or to grow the root disk. The root disk cannot shrink. Zero-valued fields are left unchanged.

```go
_, err = client.Workspaces.Stop(ctx, ws.ID, nil)
_, err = client.Workspaces.Wait(ctx, ws.ID, kibotos.WaitWorkspaceParams{
	Statuses: []kibotos.WorkspaceStatus{kibotos.WorkspaceStatusStopped},
	Timeout:  2 * time.Minute,
})

ws, err = client.Workspaces.Update(ctx, ws.ID, kibotos.UpdateWorkspaceParams{
	Resources: &kibotos.WorkspaceResourcesInput{
		VCPUs:     4,
		MemoryMiB: 8192,
		DiskMiB:   40960,
	},
})

_, err = client.Workspaces.Start(ctx, ws.ID, nil)
```

## Start and Stop

```go
// Graceful stop
_, err = client.Workspaces.Stop(ctx, ws.ID, nil)
_, err = client.Workspaces.Wait(ctx, ws.ID, kibotos.WaitWorkspaceParams{
	Statuses: []kibotos.WorkspaceStatus{kibotos.WorkspaceStatusStopped},
	Timeout:  time.Minute,
})

// Force immediate power-off
_, err = client.Workspaces.Stop(ctx, ws.ID, &kibotos.StopWorkspaceParams{
	Force: true,
})

// Start a stopped or failed workspace with an optional timeout override
_, err = client.Workspaces.Start(ctx, ws.ID, &kibotos.StartWorkspaceParams{
	Timeout: &kibotos.TimeoutSpec{
		Seconds: 7200,
		Action:  kibotos.TimeoutActionStop,
	},
})
```

## Update Timeout Policy

Resets the expiration policy on an available workspace:

```go
ws, err = client.Workspaces.SetTimeout(ctx, ws.ID, kibotos.SetWorkspaceTimeoutParams{
	Seconds: 7200,
	Action:  kibotos.TimeoutActionStop, // or kibotos.TimeoutActionDelete
})
```

## Configure Outbound Network

`client.Workspaces.SetNetwork(ctx context.Context, id string, params WorkspaceNetworkInput, opts ...RequestOption) (*Workspace, error)`

Replaces the whole outbound policy (`PUT /v1/workspaces/{id}/network`). `Network.Applied` is `nil` while the workspace is not running and points to `true` once a running workspace has confirmed the policy.

```go
ws, err = client.Workspaces.SetNetwork(ctx, ws.ID, kibotos.WorkspaceNetworkInput{
	Mode: kibotos.NetworkModeDenyAll, // or kibotos.NetworkModePublicInternet
})
fmt.Println(ws.Network.Mode)
if ws.Network.Applied != nil {
	fmt.Println(*ws.Network.Applied)
}
```

Allow and deny lists, egresses, resolvers, and `DrainSeconds` are covered in [Packs & Networking](./packs-and-networking#outbound-network-policy).

## Attach and Detach Volumes

Volumes must be in the same zone as the workspace. Use `SetVolumes` on a stopped or failed workspace to replace the full attachment list. Include every binding you want to keep, and pass an empty or nil slice to detach all volumes.

```go
ws, err = client.Workspaces.SetVolumes(ctx, ws.ID, []kibotos.WorkspaceVolumeInput{
	{ID: "vol_data", MountPath: "/data"},
	{ID: "vol_cache", MountPath: "/cache", DeleteWithWorkspace: true},
})
```

**Warning:** `AttachVolume` (`PUT /v1/workspaces/{id}/volume`) replaces all existing attachments with a single volume. `DetachVolume` (`DELETE /v1/workspaces/{id}/volume`) detaches all volumes. Use `SetVolumes` to add or remove individual bindings on a multi-volume workspace.

```go
ws, err = client.Workspaces.AttachVolume(ctx, ws.ID, kibotos.AttachVolumeParams{
	ID:        "vol_01j9...",
	MountPath: "/data",
})
ws, err = client.Workspaces.DetachVolume(ctx, ws.ID)
```

## Set Packs

`client.Workspaces.SetPacks(ctx context.Context, workspaceID string, packs []string, opts ...RequestOption) (*Workspace, error)`

Replaces the Pack list with up to four unique Pack IDs (`PUT /v1/workspaces/{id}/packs`). The change takes effect on the next start. An empty or nil slice clears the list.

```go
ws, err = client.Workspaces.SetPacks(ctx, ws.ID, []string{"node-22"})
for _, pack := range ws.Packs {
	fmt.Println(pack.ID, pack.Revision, pack.ProvidedCapabilities)
}
```

Browse available Packs with `client.Packs`. See [Packs & Networking](./packs-and-networking#packs).
