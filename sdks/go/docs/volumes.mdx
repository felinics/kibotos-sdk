---
title: Volumes
description: Create, list, iterate, update, resize, delete, and wait for persistent Kibotos volumes, and attach them to workspaces, in Go.
---

Manage persistent storage volumes via `client.Volumes` (`*kibotos.VolumesService`). A workspace can mount one or more volumes from its own zone. Bind them at creation, or while the workspace is stopped or failed.

## Create a Volume

`client.Volumes.Create(ctx context.Context, params CreateVolumeParams, opts ...RequestOption) (*Volume, error)`

Provisions a volume asynchronously (`POST /v1/volumes`, HTTP `202 Accepted`). `SizeGiB` must be greater than zero.

```go
created, err := client.Volumes.Create(ctx, kibotos.CreateVolumeParams{
	Name:    "datasets-cache",
	Zone:    "global-1",
	SizeGiB: 50,
	Labels:  map[string]string{"team": "ml"},
})
if err != nil {
	log.Fatal(err)
}

vol, err := client.Volumes.Wait(ctx, created.ID, kibotos.WaitVolumeParams{
	Statuses: []kibotos.VolumeStatus{
		kibotos.VolumeStatusAvailable,
		kibotos.VolumeStatusFailed,
	},
	Timeout: 2 * time.Minute,
})
```

## List and Iterate Volumes (`iter.Seq2`)

### Single Page (`List`)

Returns `*kibotos.MultiZonePage[kibotos.Volume]`. Use `kibotos.Ptr(false)` or `kibotos.Ptr(true)` for the optional `Attached` filter:

```go
page, err := client.Volumes.List(ctx, &kibotos.VolumeListParams{
	Zone:     "global-1",
	Attached: kibotos.Ptr(false),
	Labels:   map[string]string{"team": "ml"},
	Limit:    25,
})
```

### Auto-Pagination (`Iter`)

```go
for vol, err := range client.Volumes.Iter(ctx, &kibotos.VolumeListParams{
	Attached: kibotos.Ptr(true),
}) {
	if err != nil {
		log.Fatal(err)
	}
	fmt.Printf("%s (%d GiB) status=%s\n", vol.ID, vol.SizeGiB, vol.Status)
}
```

## Get and Update (`Nullable[T]`)

```go
vol, err := client.Volumes.Get(ctx, "vol_01j9...")

vol, err = client.Volumes.Update(ctx, vol.ID, kibotos.UpdateVolumeParams{
	Name: kibotos.Some("datasets-v2"),
	Labels: map[string]*string{
		"tier":      kibotos.Ptr("hot"),
		"old_label": nil, // deletes label key
	},
})

// Clear name explicitly
vol, err = client.Volumes.Update(ctx, vol.ID, kibotos.UpdateVolumeParams{
	Name: kibotos.Null[string](),
})
```

## Resize a Volume

`client.Volumes.Resize(ctx context.Context, id string, params ResizeVolumeParams, opts ...RequestOption) (*Volume, error)`

Grows an existing `available` volume asynchronously (`POST /v1/volumes/{id}/resize`, HTTP `202 Accepted`; volumes bound to a stopped/failed workspace remain `available` and can be resized):

```go
_, err = client.Volumes.Resize(ctx, vol.ID, kibotos.ResizeVolumeParams{
	SizeGiB: 100,
})
if err != nil {
	log.Fatal(err)
}

vol, err = client.Volumes.Wait(ctx, vol.ID, kibotos.WaitVolumeParams{
	Statuses: []kibotos.VolumeStatus{
		kibotos.VolumeStatusAvailable,
		kibotos.VolumeStatusFailed,
	},
	Timeout: 3 * time.Minute,
})
```

## Delete a Volume

`client.Volumes.Delete(ctx context.Context, id string, opts ...RequestOption) (*Volume, error)`

Deletes an unbound volume (`WorkspaceID == nil`) asynchronously (`DELETE /v1/volumes/{id}`, HTTP `202 Accepted`):

```go
deleting, err := client.Volumes.Delete(ctx, vol.ID)
if err != nil {
	log.Fatal(err)
}
fmt.Println(deleting.Status) // deleting
```

## Wait for Volume Status

Available `VolumeStatus` constants: `VolumeStatusCreating`, `VolumeStatusAvailable`, `VolumeStatusAttached`, `VolumeStatusResizing`, `VolumeStatusDeleting`, `VolumeStatusFailed`, `VolumeStatusLost`, `VolumeStatusUnknown`.

Volume statuses follow native Kibotos 1:1 semantics: `WorkspaceID` expresses whether a volume is bound to a workspace; `VolumeStatusAvailable` means ready and not currently mounted to a running workspace (including volumes bound to a stopped/failed workspace); `VolumeStatusAttached` means actively mounted to a running workspace; `VolumeStatusLost` means the underlying storage pool was lost and data is unrecoverable.

When `params.Timeout` is zero, `Wait` uses `ctx`'s deadline if set, or defaults to `30s`. Timeouts longer than `60s` automatically chunk across `<= 60s` server wait windows.

## Attach Volumes to a Workspace

Volume bindings are managed on the workspace. Set `Volumes` on `Workspaces.Create`, or replace the full list on a `stopped` or `failed` workspace with `Workspaces.SetVolumes`:

```go
ws, err := client.Workspaces.Create(ctx, kibotos.CreateWorkspaceParams{
	Template: kibotos.WorkspaceTemplateSpec{ID: "python-3.12"},
	Zone:     vol.Zone,
	Volumes: []kibotos.WorkspaceVolumeInput{
		{ID: vol.ID, MountPath: "/data"},
	},
})
if err != nil {
	log.Fatal(err)
}

// Replace the bindings later (the workspace must be stopped or failed)
ws, err = client.Workspaces.SetVolumes(ctx, ws.ID, []kibotos.WorkspaceVolumeInput{
	{ID: vol.ID, MountPath: "/data"},
	{ID: "vol_cache", MountPath: "/cache"},
})
```

| `WorkspaceVolumeInput` field | Type | Description |
| --- | --- | --- |
| `ID` | `string` | Volume ID. The volume must be unbound and in the workspace's zone. |
| `MountPath` | `string` | Absolute mount path inside the workspace. |
| `DeleteWithWorkspace` | `bool` | Delete the volume when the workspace is deleted. |

A bound volume reports the workspace in `WorkspaceID`. See [Workspaces](./workspaces#attach-and-detach-volumes) for `SetVolumes` and the single-volume `AttachVolume` / `DetachVolume` methods.
